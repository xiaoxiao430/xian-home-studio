# 主卧两版与同一部楼梯的两层研究

本轮保留原 A/B，从发布时的最新项目复制四个独立组合。线上一楼在实施期间发生的餐岛位置修改也保留，不用开始实施时的旧布局覆盖。私人原图、照片、完整项目与口令不进入代码仓库。

## 按最后确认的布局

- 七块原标面积共39.2㎡，含原0.8㎡全部归主卧。中部原2㎡小间改为公共直饮、杂物收纳，北门及东侧卧室入口保留。
- 两版都有双台盆、大浴缸、独立淋浴、可关门如厕、2米床垫研究及封闭衣帽收纳。床头床尾对调180°，床架2100×2250移至图纸下方，床头贴原分隔墙；床头柜随床移动。
- 干区版化妆接双台盆。阳台版化妆依托阳台下端墙垛，在阳台窗户侧坐下；900×450浅台、700宽镜面和450×450紧凑椅配合，镜面对应实墙。700×1900躺椅移到阳台上端。
- 附件中的原布局仅作参考关系，不把图中的单台盆或隔墙直接复制为已确认设计。
- 楼梯保留每层不同的原图坐标，原占地、向过厅扩展及自由修改两层联动。平面、立面、剖面、三维和导出共用梯段几何；二楼显示向下楼梯。
- 深咖木作、奶咖地面、浅墙及局部奢石是材质方向。软包沙发和躺椅为几何表达，实际纹理、触感和坐躺舒适度仍需选样。

## 有意保留的取舍

阳台版比干区版多1000 mm衣帽柜正面长度。床架暂按2100×2250，床侧直接净距约600/601 mm，新床尾至图纸上墙的开敞区深度2258 mm；不会把它显示为满足900通道目标。浴缸前1080、如厕前610是方案几何值，须结合真实产品、门扇与动作复核。25 mm网格的夜间床侧路线估算565；干区版套间进入路线估算686，阳台版926。网页保留偏窄提示，未下调目标来消除提示。

阳台化妆椅后至窗约320 mm，后退范围暂按300 mm，需侧向离座；化妆台与躺椅之间约811 mm进入带。躺椅侧边540 mm为到原洞口内侧线的余量，两区连通，不当作主要连续通道。楼梯向过厅扩大600时，二楼对应直接通行带由1260减至660。两种楼梯均是占地和转向研究，不代表踏步、净高、洞口或结构已通过。
