## 导出读回与视觉核验

- **PDF：** `pdfinfo` 确认 1 页、1190.55 × 841.89 pt，即 A3 横向。`pdffonts` 确认 `MicrosoftYaHei-6660`、CID TrueType、Identity-H、`emb=yes`、`uni=yes`；中文文字可提取。字体已嵌入，未将字体工具的 `sub=no` 误写成子集嵌入。
- **局部交底：** 最终构建的 PDF 经 Poppler 渲染后查看，中文清晰，房间讨论范围有定位框，立面墙线不越出右侧绘图区。空间范围注明为沟通圈选，不当作已实测闭合边界。
- **DXF：** 对浏览器下载文件使用 `ezdxf.readfile()` 重新读取并审计，`$INSUNITS=4`（mm），含 9 个 `DIMENSION` 实体，审计错误 0、自动修复 0。尺寸不是仅有文字和线段的扁平图片。

## 本轮发现并复核的缺陷

1. 受控选择状态双向同步形成反馈循环，编辑字段重复重建。调整为受控状态后，拖动与连续编辑通过。
2. 文件输入框清空导致异步读取的 `FileList` 为空。上传前复制文件数组后恢复正常。
3. 上传资料缺少必需元数据字符串造成服务器验证失败。前后端补齐默认值后，上传、说明编辑与刷新均通过。
4. 局部空间 PDF 未应用嵌套 SVG 的裁剪边界，长墙线越过面板。增加 PDF 视口裁剪并使用最终构建重新导出、渲染后通过。

## 复现方式与范围

浏览器脚本为 [scripts/test-studio-browser.mjs](../scripts/test-studio-browser.mjs)，只允许访问 `localhost` 或 `127.0.0.1`，避免误改正式项目。凭据从受保护的本机 JSON 文件读取，未写入代码、报告或日志。

```sh
STUDIO_TEST_URL=http://127.0.0.1:18892/xian-home/ \
STUDIO_TEST_CREDENTIALS=/private/path/to/test-credentials.json \
STUDIO_TEST_OUTPUT=/tmp/xian-studio-browser-qa \
node scripts/test-studio-browser.mjs
```

用 `STUDIO_TEST_FILTER='A3 PDF'` 可只复测交底导出。测试输出、截图、下载文件、测试快照及草稿均留在本机临时目录，不随仓库发布。

本报告的移动检查是浏览器视口与 User-Agent 模拟，**没有使用实体手机或真实微信客户端**。本机交互验证不证明中国大陆或新加坡的地区可达性；地区检测另见网络报告。布局测试不等于结构可拆改审批或尺寸现场复测。双浏览器冲突测试覆盖布局草稿保留，未声称穷举所有资料说明同时修改的组合。
