# 西安的家 · 两层空间工作台

私人住宅方案编辑器。源码使用 Vinext/React，部署为 Sites Cloudflare Worker。

- 两层可编辑毫米平面：家具、门窗、墙体、边界节点、独立上下阳台外推。
- 一楼来源为用户确认的最新布局；二楼由原始墙体、尺寸和面积三份PDF矢量复核。
- 所有原墙仅分为疑似结构/未确认。`confirmed` 只供用户依据结构资料主动标记，初始数据没有确证承重墙。
- D1 保存每位用户的布局、参考图说明、渲染记录；R2 保存图片。
- SSR 输出实际SVG；关闭脚本时仍能看到已保存的底图。
- 导入具有完整模式校验和SVG元素/属性白名单；更新使用修订号防止并发覆盖。
- 阳台外推单独维护上下转折节点，保留原柱，墙体改动保留痕迹。
- 图像服务凭据只存服务端 `OPENAI_API_KEY`；未配置时明确显示待连接。
- 生成调用保持请求连接，不伪装成可在后台永久运行的任务。
- 效果图任务导出包含当前布局、材质、说明和最多5张参考图，可交给Codex继续适配。

## 开发

`npm run dev`；`npm run build`；`npm run db:generate`。
本地预览使用 starter 的开发登录。生产身份由 Sites 私人访问控制提供。
数据库迁移首次发布后不可改写，应追加迁移。

## 关键文件

- `data/seed.json`：已核对的两层初始方案及原图来源。
- `lib/model.ts`：结构、导入验证、阳台轮廓操作。
- `app/Editor.tsx` / `app/Plan.tsx`：编辑器及服务器可渲染平面。
- `app/api`：保存、图片上传、图片读取和效果图生成。
